# Always Push to GitHub

**CRITICAL RULE**: ทุกครั้งที่มีการสร้าง แก้ไข หรือลบไฟล์ในโปรเจกต์นี้ คุณ **ต้อง** รันคำสั่ง Git เพื่อ Commit และ Push ขึ้น GitHub เสมอ เพื่อให้การแก้ไขอัปเดตไปที่หน้าเว็บจริง (Live Website) ทันที ห้ามลืมเด็ดขาด

**ขั้นตอนการทำงาน (Action Required):**
เมื่อคุณเขียนโค้ดเสร็จแล้ว ก่อนจบการสนทนาในรอบนั้นๆ ให้รันคำสั่งด้านล่างนี้ผ่าน Terminal ทันที:
`git add . ; git commit -m "update: [สรุปสิ่งที่คุณเพิ่งแก้ไป]" ; git push origin dev`

(หาก Branch ปัจจุบันไม่ใช่ dev ให้ push ไปยัง branch นั้นๆ)

หากคุณละเลยกฎข้อนี้ จะถือเป็นการฝ่าฝืนคำสั่งขั้นร้ายแรงของ User
