📘 คู่มือการเพิ่มข้อมูลเพลง

1. วิธีการหา BPM และ คีย์

  • ปุ่ม 🤖 AI: กดที่ปุ่มหุ่นยนต์ในหน้าต่าง "เพิ่มเพลง" ระบบจะช่วยค้นหา BPM และคีย์ให้โดยอัตโนมัติ
  • เช็คจากเว็บไซต์: สามารถนำชื่อเพลงไปค้นหาได้ที่ SongBPM.com หรือ Tunebat.com

2. ตารางเทียบเคียงคีย์ (Key Mapping)

ระบบจัดเก็บคีย์ในรูปแบบจำนวนชาร์ป(#)/แฟลต(b) สามารถเทียบเป็นคีย์ตัวอักษรได้ดังนี้:

ระบบคีย์สากล (Major/Minor)
C / AmC / Am
1#G / Em
2#D / Bm
3#A / F#m
4#E / C#m
5#B / G#m
ระบบคีย์สากล (Major/Minor)
1bF / Dm
2bBb / Gm
3bEb / Cm
4bAb / Fm
5bDb / Bbm
💡 ทริค: กดปุ่ม "🔤 อักษร" บนแถบเครื่องมือเพื่อสลับการแสดงผลคีย์ในตารางได้ตลอดเวลา

3. เกณฑ์การแบ่งยุค (Era)

  • 80s: ปี พ.ศ. 2523 - 2532
  • 90s: ปี พ.ศ. 2533 - 2542 (ยุคอัลเทอร์เนทีฟรุ่งเรือง)
  • 2000s (00s): ปี พ.ศ. 2543 - 2553
  • 2010s (10s): ปี พ.ศ. 2554 - 2562
  • 2020s (20s): ปี พ.ศ. 2563 - ปัจจุบัน
